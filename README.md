# Quiz de Python

Quiz interativo de linha de comando com perguntas de múltipla escolha e pontuação final.

## Requisitos

- Python 3.9 ou superior

## Como executar

```bash
python quiz.py
```

Para executar os testes:

```bash
python -m unittest discover -s tests -v
```

## O que este projeto pratica

Funções, estruturas de dados, entrada e saída no terminal e testes isolados da interação com o usuário.
